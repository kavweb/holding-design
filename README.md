# گروه صنعتی و سرمایه‌گذاری دکتر حسن قاسمی | هلدینگ قاسمی

وب‌سایت نسخه میانی (Static) ساخته‌شده با **React + Vite + TypeScript + Tailwind CSS v4**.

## ویژگی‌های فعلی
- طراحی مدرن صنعتی (تم تیره + طلایی)
- کاملاً RTL و فارسی با فونت Vazirmatn
- صفحات: خانه، درباره ما، فولاد، صادرات، املاک، اخبار، پروژه‌ها، سرمایه‌گذاری، دفاتر منطقه‌ای، تماس
- ساختار ناوبری بر اساس نقشه سایت PDF
- بخش‌های پیشرفته (CRM، قیمت زنده، پنل کاربری، نقشه تعاملی و …) با برچسب «در دست ساخت»

## راه‌اندازی محلی

```bash
cd ghasemi-holding
npm install
npm run dev
```

سپس مرورگر را روی آدرس نمایش‌داده‌شده (معمولاً http://localhost:5173) باز کنید.

## بیلد برای استقرار روی پارس‌پک

```bash
npm run build
```

خروجی در پوشه `dist` قرار می‌گیرد. محتویات `dist` را روی هاست استاتیک پارس‌پک آپلود کنید.

## لوگو
لوگوی اختصاصی خود را در `public/` قرار دهید و مسیر آن را در `Header.tsx` و `Footer.tsx` جایگزین کنید.

## نکات هاست پارس‌پک
- این نسخه کاملاً استاتیک است و به Node.js سمت سرور نیاز ندارد.
- برای روتینگ React Router در هاست‌های استاتیک، فایل `.htaccess` یا تنظیمات SPA fallback لازم است (تمام مسیرها به index.html هدایت شوند).
